## 🚀 Deployment to Render.com

This application is built as a high-performance React + TypeScript + Vite SPA, pre-configured for **Render Static Sites**.

### Deploy via Render Blueprint (`render.yaml`):
1. Push this repository to GitHub.
2. Log in to [Render Dashboard](https://dashboard.render.com).
3. Click **New +** $\to$ **Blueprint**.
4. Connect this GitHub repository. Render will automatically detect `render.yaml`.
5. Click **Apply** to deploy.

### Manual Render Setup:
If setting up as a manual Static Site on Render:
- **Environment**: `Static`
- **Build Command**: `npm install && npm run build`
- **Publish Directory**: `dist`
- **Rewrite Rule**:
  - Source: `/*`
  - Destination: `/index.html`
